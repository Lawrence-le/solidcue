# Create Skill

## Purpose

Define the standard contract for generating any agent `SKILL.md` file.
This skill ensures consistent structure and behavior across different LLMs.

## When To Use

Use this skill when the system needs to create or rewrite an agent skill file.

Do not use this skill for:

- executing an existing agent
- creating the agent config
- router-only clarification
- workspace profile setup

## Required Output Contract

Every generated agent skill file must contain these sections in order:

1. `# Skill`
2. `Purpose`
3. `When To Use`
4. `Workflow`
5. `Required Inputs`
6. `Validation Rules`
7. `Output Contract`

## Rules

- Keep the section order stable.
- Keep headings stable.
- Do not invent unsupported capabilities.
- Keep wording specific to the target agent, but preserve the structure.
- If a section is not relevant, state `Not specified` rather than omitting it.
- The `Workflow` must cover the spec's `key_tasks`.
- If the spec's `produces_artifacts` is true, the `Workflow` must end by saving the
  output to `artifact_destination` **verbatim** — the exact path and/or filename the
  human provided — and `Output Contract` must name that same destination.

## Workflow

1. Read the source materials for the target agent.
2. Identify the role, scope, and expected behavior.
3. Extract the source-of-truth rules that the agent must follow.
4. Write the agent skill using the canonical contract.
5. Verify the final file is concise, structured, and runnable.

## Required Inputs

- agent name
- agent key
- role or purpose
- key tasks
- artifact output decision and destination (path/filename), when applicable
- source materials
- task scope
- tool usage constraints

## Validation Rules

- The skill must be grounded in source materials.
- The skill must not contradict the agent config.
- The skill must not define behavior that the agent cannot perform.
- The skill must stay consistent even when generated by different models.

## Output Contract

The generated file must be saved as:

- `solidcue/agents/<agent_key>/SKILL.md`

And must remain compatible with the agent graph prompt loaders.
